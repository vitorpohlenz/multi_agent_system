# TECH RUNBOOK: COMMON SUPPORT SCENARIOS

## Scenario 1: User cannot log in to the SaaS dashboard.
1) Verify that the user is using the correct login URL and corporate email.
2) Ask the user to try logging in via incognito/private browsing mode.
3) Check if the user recently changed their identity provider password.
4) If the account is locked due to failed attempts, instruct the user to wait 30 minutes or escalate to IT to reset.

## Scenario 2: VPN connection fails.
1) Confirm that the user is on a stable network connection.
2) Ask the user to restart the VPN client and try again.
3) Validate that the user's account is active and that MFA is working.
4) If the issue persists, collect logs and escalate to the network team.

## Scenario 3: API returns HTTP 500 for multiple customers.
1) Check the status page and incident Slack channel for ongoing incidents.
2) Review application logs for recent deployments or configuration changes.
3) If reproducible across customers, open an incident ticket and follow the incident management policy.
